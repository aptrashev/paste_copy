# Cross-platform clipboard manager

Desktop-приложение для macOS и Windows, которое локально сохраняет историю буфера обмена и позволяет быстро найти и повторно вставить фрагмент. Рабочее название и визуальная айдентика пока не выбраны.

Проект находится на стадии архитектуры: кода приложения и файлов зависимостей ещё нет. Базовый стек зафиксирован как **Tauri 2 + Rust + React/TypeScript**, локальное хранилище — **SQLite/FTS5 + зашифрованный blob store**.

## Границы первой версии

- Поддерживаемые системы MVP: macOS 13+ и Windows 10 22H2/Windows 11.
- Linux отложен до отдельного post-MVP решения: проект не собирает, не тестирует и не распространяет Linux-версию.
- История, поиск и настройки работают локально. Cloud sync, мобильные клиенты, OCR, sharing и AI/MCP не входят в MVP.
- Любая сборка, способная хранить реальные пользовательские данные, использует зашифрованное хранилище. Упрощённый storage разрешён только автоматическим тестам с синтетическими fixtures.
- MVP распространяется прямыми подписанными установщиками: notarized/signed `.dmg` для macOS и code-signed `.msi` для Windows. App stores не входят в MVP.
